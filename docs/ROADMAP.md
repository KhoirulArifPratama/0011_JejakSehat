# Roadmap Pengembangan

## Minggu 1 — Fondasi

- Menyiapkan repository dan aturan file yang diabaikan.
- Menyiapkan project Android Compose.
- Menyiapkan struktur backend Express.
- Menyusun skema database dan autentikasi awal.
- Mendokumentasikan ruang lingkup dan arsitektur.

## Tahap berikutnya

- Integrasi Retrofit antara Android dan backend.
- Menyimpan sesi login menggunakan DataStore.
- Menambahkan validasi dan penanganan error API.
- Menyempurnakan CRUD rekam medis dan upload dokumen.
- Menambahkan pengujian fitur dan dokumentasi demo.
